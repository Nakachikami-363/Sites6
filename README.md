# Antonio Mina — Consultoria Imobiliária

Site estático pronto para publicação gratuita no **GitHub Pages**.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub (por exemplo, `antonio-mina-imoveis`).
2. Envie os arquivos desta pasta para a raiz do repositório (`index.html` e a pasta `assets/`).
3. No GitHub, acesse **Settings > Pages**.
4. Em **Build and deployment > Source**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde alguns instantes até o site ficar disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.
